# Dev notes — EMP-7.1

## Come ripetere il gate

```bash
cd laravel
./vendor/bin/phpstan analyse Modules --memory-limit=-1 --no-progress --error-format=raw | grep "Modules/Employee/"
```

`phpstan analyse Modules/Employee` da solo puo' essere verde anche con l'albero sotto il 99 %: la soglia e' full-tree.

## Regole emerse

- Closure su `Collection<int, Model>`: tipizzare col model, non lasciare `$x` nudo.
- Scope Eloquent legacy (`scopeFoo($query)`): `Builder $query`, il docblock `Builder<static>` fa il resto.
- `mixed` ammesso solo per valori davvero ignoti (state Filament, `pluck()`); la closure poi restringe.
- Prima di tipizzare un parametro che sovrascrive un metodo del parent leggere la firma del parent (LSP).
